# Ashwake

**Задачи, привычки и личные ритуалы в одном приложении для Android.** Ashwake работает без аккаунта и интернета: данные сохраняются на телефоне. Если подключить свой сервер, становятся доступны профиль, друзья, пространство пары, синхронизация задач и зашифрованные облачные копии.

[Скачать APK для Android](https://raw.githubusercontent.com/Xver1Xrd/ashwake/v1.2.1/releases/ashwake-v1.2.1-debug.apk) · [Посмотреть сборки в репозитории](releases/) · [Сообщить о проблеме](https://github.com/Xver1Xrd/ashwake/issues)

> APK по ссылке — **отладочная сборка 1.2.1** из исходников этого репозитория. Она устанавливается как `dev.ashwake.debug`; данные такой установки хранятся отдельно от сборки с идентификатором `dev.ashwake`. Архивы **Source code (zip/tar.gz)** на GitHub содержат исходники, а не приложение.

## Что можно делать

| Раздел | Возможности |
| --- | --- |
| **Сегодня** | Смотреть задачи на выбранную дату, отмечать привычки и видеть ход дня. Прогресс задач и отметки привычек считаются отдельно. |
| **Задачи** | Создавать задачи и подзадачи, задавать срок, время, приоритет, теги, проекты и повторы; использовать шаблоны, переносить задачи и отправлять их в корзину. В отдельном просмотре доступны заметка, детали задачи и карточки вложений. Для фото открывается галерея, для файлов — системный выбор документов. |
| **Привычки** | Выбирать расписание, отмечать выполнение, смотреть историю, серии и статистику. Периодическая привычка учитывается по своему периоду, а не как ежедневная задача. |
| **Ещё** | Открывать отказы, таймеры и рутины, статистику, вечерний ритуал, корзину и настройки. Здесь же находится поиск по задачам, архиву и заметкам. |
| **Оформление** | Менять тему, акцентный цвет и значок приложения. |

Дополнительно доступны календарь и планирование дня, напоминания, виджеты, импорт CSV из других приложений и блокировка выбранных приложений по правилу. Блокировка требует отдельных разрешений Android и выключена по умолчанию.

## Начать пользоваться

1. Установите APK на устройство с **Android 8.0 (API 26)** или новее. Если Android запросит разрешение на установку из выбранного приложения, выдайте его для этого файла.
2. Создайте задачу на экране «Сегодня» или откройте вкладку «Задачи». Аккаунт для этого не требуется.
3. Для резервной копии откройте **Ещё → Настройки → Данные и бэкапы**. Выберите папку и создайте копию; при восстановлении сначала проверьте содержимое архива, затем подтвердите замену данных.

После выбора папки приложение может записывать локальную копию примерно раз в сутки. **Автоматические локальные копии сохраняются без пароля**; ручную копию можно защитить паролем. Выбирайте для папки место, доступ к которому контролируете. Потерянный пароль от зашифрованного архива восстановить нельзя.

## Аккаунт и синхронизация

Онлайн-функции работают, только если APK собран с адресом API и доступен совместимый сервер. В обычной сборке без адреса API экран **Ещё → Настройки → Аккаунт и синхронизация** показывает интерактивный предпросмотр профиля: введённые там данные не создают учётную запись.

При подключённом API доступны профиль с `@username`, точный поиск пользователей, заявки в друзья и пара с личным и общим пространствами. Телефон шифрует содержимое синхронизируемых задач до отправки. Сервер управляет доступом и хранит зашифрованные записи, но видит служебные сведения: профили, связи пользователей, идентификаторы пространств, типы записей, версии и время изменений.

**Границы текущей синхронизации:** между устройствами передаются задачи. Привычки, отказы, рутины, локальные картинки значков и прикреплённые файлы не становятся общими через синхронизацию задач. Для переноса всего набора локальных данных используйте резервную копию. Облачная копия шифруется на телефоне и требует сохранённого кода восстановления; без него данные расшифровать нельзя.

## Сборка Android-приложения

Нужны JDK **17 или новее**, Android SDK **35** и локаль UTF-8. Путь к SDK можно задать через `ANDROID_HOME` или в файле `local.properties` (`sdk.dir=/путь/к/Android/Sdk`). Gradle Wrapper уже находится в репозитории.

```bash
git clone https://github.com/Xver1Xrd/ashwake.git
cd ashwake
LANG=C.UTF-8 ./gradlew :app:assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Для установки на подключённое устройство выполните `./gradlew :app:installDebug`.

Для разработки с локальным API в эмуляторе:

```bash
./gradlew :app:assembleDebug -Pashwake.apiBaseUrl=http://10.0.2.2:8080
```

`10.0.2.2` ведёт из Android-эмулятора на компьютер разработчика. Для телефона укажите доступный ему адрес сервера. HTTP допускается только в debug-сборке; для release нужен HTTPS.

Релизную сборку можно проверить командой `./gradlew :app:assembleRelease`. Для устанавливаемого и обновляемого релиза потребуется собственная подпись: переменные `ASHWAKE_KEYSTORE`, `ASHWAKE_KEYSTORE_PASSWORD`, `ASHWAKE_KEY_ALIAS` и `ASHWAKE_KEY_PASSWORD`. Без них Gradle создаст неподписанный release APK. Не кладите ключ и пароли в репозиторий.

## Локальный запуск API

API написан на Python 3.12 и FastAPI. Для разработки он может использовать SQLite; развёртывание из `server/compose.yaml` использует PostgreSQL, Caddy и приватное S3-хранилище для облачных копий.

```bash
cd server
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
export ASHWAKE_ENVIRONMENT=development
export ASHWAKE_JWT_SECRET="$(openssl rand -base64 48)"
.venv/bin/uvicorn app.main:app --reload --port 8080
```

Проверка: `http://127.0.0.1:8080/healthz`. В разработке таблицы создаются при старте. В production схему обновляет Alembic. Переменные сервера перечислены в [`server/.env.example`](server/.env.example); порядок развёртывания — в [`server/README.md`](server/README.md). Не используйте значения `CHANGE_ME` и не публикуйте `.env`.
